## About

I'm a data science student passionate about the intersection of **theoretical computer science** and **machine learning**. My work explores how mathematical foundations—particularly **category theory**—can inform the design and understanding of learning systems.

Currently conducting undergraduate research on categorical approaches to automatic differentiation and gradient-based learning, implementing formal abstractions in functional programming languages to verify theoretical properties empirically.

- **Statistical Learning** — Rigorous frameworks for model selection and generalization

## Featured Projects

### 🔬 Categorical Backpropagation in Haskell
*Undergraduate Research Project (Iniciação Científica)*

Implementation of the **Learner** category from *Backprop as a Functor* (Fong, Spivak, Tuyéras, 2019) with empirical verification of categorical laws. Type-level parameter spaces using heterogeneous lists for compositional guarantees.

**Stack:** Haskell, GHC 9.6, Category Theory  
**Advisor:** Prof. Alexandre Garcia de Oliveira, PhD (USP)

---

### 🧠 [Neural Network from Scratch](https://github.com/0kauaa/my-mlp)
Custom MLP implementation with detailed mathematical documentation in LaTeX. Focus on understanding backpropagation mechanics and gradient flow.

**Stack:** Python, NumPy, LaTeX

---

### 📊 [Dimensionality Reduction on App Store Data](https://github.com/0kauaa/playstore-with-pca)
Applied PCA to high-dimensional app metadata for pattern discovery and feature engineering.

**Stack:** Python, scikit-learn, pandas

---

### 📈 Time Series Forecasting with Prophet

**Stack:** Python, Prophet, LaTeX/Overleaf
